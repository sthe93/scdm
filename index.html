SCDM

SCDM is a web application in development for organizing media, reviewing captions, and tracking publishing jobs.

TikTok integration

The planned inbox workflow lets an authorized user select a video and send it to their TikTok inbox for review. The user decides whether to post it in TikTok.

This public site describes the project. It does not sign you in, collect videos, or publish content.
